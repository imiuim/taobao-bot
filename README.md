# 淘宝闪购-幸运星任务自动化 (AutoJs6)

## 使用步骤
1. 手机安装 AutoJs6(应用商店或 GitHub Releases)
2. 打开 AutoJs6 → 开启无障碍服务(系统会引导)
3. 新建脚本粘贴 1_登录.js 内容(或导入),运行
4. 脚本会自动:打开淘宝 → 同意隐私 → 进登录页 → 填手机号 → 发验证码
5. 把收到的验证码输入完成登录(手动)
6. 登录成功后运行 2_幸运星任务.js:自动进闪购 → 找幸运星 → 循环做任务
